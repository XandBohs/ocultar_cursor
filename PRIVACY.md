# Privacy Policy / Política de Privacidade

Last updated: September 22, 2026  
Última atualização: 22 de setembro de 2026

## English

### Summary

Hide Cursor in Fullscreen does not collect, transmit, sell, or share personal information, browsing history, analytics, or telemetry.

### Data stored locally

The extension stores only the list of domains that the user explicitly authorizes. This list is kept in the browser's local extension storage and is not transmitted outside the user's device.

### Permissions

- `activeTab` is used to identify the current tab's domain when the user opens the extension popup.
- `scripting` is used to activate the cursor-hiding behavior on domains authorized by the user.
- `storage` is used to save the authorized-domain list locally in the browser.
- Optional host permissions are requested only after the user chooses to authorize a domain. They allow the extension to operate on that domain and its subdomains.

The extension does not execute remotely hosted code and does not make network requests to a developer-controlled server.

### Changes and contact

Material changes to this policy will be documented in this repository. Questions and support requests can be submitted through the project's [GitHub Issues](https://github.com/XandBohs/ocultar_cursor/issues).

## Português do Brasil

### Resumo

O Ocultar Cursor em Tela Cheia não coleta, transmite, vende ou compartilha informações pessoais, histórico de navegação, dados analíticos ou telemetria.

### Dados armazenados localmente

A extensão armazena somente a lista de domínios que o usuário autoriza explicitamente. Essa lista permanece no armazenamento local da extensão no navegador e não é transmitida para fora do dispositivo do usuário.

### Permissões

- `activeTab` é usada para identificar o domínio da aba atual quando o usuário abre o popup da extensão.
- `scripting` é usada para ativar o comportamento de ocultar o cursor nos domínios autorizados pelo usuário.
- `storage` é usada para salvar localmente no navegador a lista de domínios autorizados.
- As permissões opcionais de host são solicitadas somente depois que o usuário escolhe autorizar um domínio. Elas permitem que a extensão funcione nesse domínio e em seus subdomínios.

A extensão não executa código hospedado remotamente e não faz requisições de rede para servidores controlados pelo desenvolvedor.

### Alterações e contato

Alterações relevantes nesta política serão documentadas neste repositório. Dúvidas e pedidos de suporte podem ser enviados pelo [GitHub Issues](https://github.com/XandBohs/ocultar_cursor/issues).
